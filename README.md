# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

每次达到报警线的推送都会生成一份**推送抄本**，冻结推送当时的测点、浓度、状态原文和校验短串，单独存档并可下载。检查员事后可以改正班测浓度，但改正不重新推送、不生成新抄本、也不改变已生成抄本的正文与校验短串；只有再次达到报警线的推送才产生新抄本。旁观账号能看抄本列表、下载抄本，但不能改正班测。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3191 |
| 接口 | http://localhost:8191 |
| PostgreSQL | localhost:54391 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| gasman | gas123456 | 可上报、可改正班测浓度、可下载抄本 |
| viewer | view123456 | 只能看、可进抄本列表并下载抄本，不能改正 |

## 启动

```bash
cd projects/12-mine-methane-shift
docker compose up --build
```

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常；回风巷行带抄本号，点进去可下载，正文含 1.40% 与校验短串。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录，并生成新抄本。
3. viewer 登录后没有上报表单，也没有改正输入；但能进抄本列表、下载抄本。
4. 对回风巷再报一笔更高报警（如 1.8%），抄本列表出现新抄本，下载最新抄本应含新浓度 1.80%。
5. 随后用 gasman 在班测列表改正该行浓度（如改成 0.40%），重新打开刚下载的那份抄本，正文浓度仍是改正前的 1.80%，校验短串也不变；班测列表当前浓度显示为 0.40%。
6. 正常班测（低于 1%）不产生抄本。
